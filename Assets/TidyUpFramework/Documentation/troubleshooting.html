Troubleshooting & FAQ

Run Tools > Tidy Up Framework > Level Validator first: it detects most configuration problems and offers one-click fixes.

Troubleshooting

SymptomCause and fix
Objects do not highlight and cannot be picked upThe object has no collider, its layer is excluded from the interactor's Interaction Mask, it is farther than Reach Distance, or Movable is off. Run Make Selected Objects Interactive.
I can hold an object but nothing happens when I aim at the shelfThe target has no aim collider. Use Add / Reset Aim Trigger on the target inspector and resize it to cover the shelf.
The ghost preview is redThe object does not match the target's Acceptance, or the target is not compatible (for example a stack point with a non-stackable object). The target inspector shows how many scene objects match.
"No space left"The target is full: row length used up, all slots taken or stack height reached.
The level never completesAn objective counts objects that cannot be placed correctly, a target requires an order the player cannot see, or a required objective is impossible. The validator reports impossible counts; check target ordering settings.
The level completes immediatelyNo objectives and no counting targets: the fallback completes when every counting target is complete. Add objectives or a target that counts towards progress.
Objects sink into or float above shelvesThe mesh pivot or bounds are unusual. Placement aligns the bottom of the combined render bounds to the surface; use Placement Euler Offset for rotated meshes or fix the pivot.
Outlines show gaps on hard edgesStore smoothed normals in UV channel 3 (the demo mesh builder does this) or use meshes with smooth normals.
No soundThe framework settings asset or audio cues are missing, or the volumes in Settings are zero. Check Resources/TidyUpFrameworkSettings.
Prompts show action names instead of keysNo TidyInputReader is active, or the action asset lacks a binding for the active control scheme.
Level Select is emptyNo catalog assigned in the framework settings, or catalog entries are empty.
Loading a level logs "not in the build scene list"Add the scene to File > Build Profiles, or use the validator fix.
Cursor stays hidden in menusScreens that should free the cursor need Locked Channels to include Cursor (the provided pause, settings and results screens lock All).
Pink materialsThe project is not using URP. Assign a URP asset in Graphics and Quality settings.
Saves do not persist on WebGLSwitch the framework settings to PlayerPrefs storage.
A dropped object floats in the airFixed in 1.1: the drop probe ignores the player capsule and held objects, and objects resting on a picked-up object settle down. If you still see it, an invisible non-trigger collider is under the drop point; make it a trigger or move it to a layer outside the Interaction Mask.
An object on a table or bench cannot be picked upThe furniture collider encloses the object. Since 1.1 the interactor reaches objects embedded up to 30 cm inside a collider, but the clean fix is a collider that matches the visible top surface.
The tutorial cannot be skipped while the cursor is lockedPress Backspace (gamepad View). The shortcut is configurable on TidyTutorialView, and Settings > Gameplay > Tutorials turns tutorials off.
Saved progress restores the wrong objectsTwo Tidy Objects share an id. Run Generate Missing Scene IDs; the Level Validator lists duplicates.
A level always starts where I left it while testingThat is the mid-level save. Use Restart in the pause menu, call DiscardSavedProgress(), untick Save Progress on the Level Manager, or delete level_*.json in the save folder.

FAQ

Can players carry more than one object?

Yes. Raise Carry Capacity on the TidyInteractor; see Carrying a stack.

Can players save in the middle of a level?

Yes. Levels autosave and resume automatically; see Saving progress inside a level.

Can I use my own character controller?

Yes. Keep a camera with TidyInteractor and provide input through ITidyPlayerInput. See Player.

Can I make a third-person or top-down game?

Yes. The interactor aims along any camera ray or a pointer position. For top-down mouse games, call RegisterTap on the reader with the mouse position or implement your own input source that always reports a pointer aim.

Does it support physics-heavy games?

Use physics profiles for objects that should tumble and be thrown. Placed objects are always kinematic for stable shelves.

How many objects can a scene hold?

Hundreds on mobile and over a thousand on desktop in the demos. Idle objects cost almost nothing; rendering is usually the limit, so batch and instance your materials.

Can I localise text?

All player-facing strings come from assets (definitions, objectives, tutorials) or prefabs, so they can be routed through Unity Localization. Input prompts are generated at runtime and can be wrapped in localised templates.

Can I delete the demo?

Yes. Delete Demo/. The framework, its prefabs, defaults and editor tools keep working. Assign your own catalog in the framework settings.

Why are there no comments in the C# code?

The code communicates through naming, small classes and Inspector tooltips; this documentation and the API reference explain design and usage.

Is there any third-party dependency?

No. Only Unity packages: URP, Input System, uGUI/TextMeshPro. All models, textures and sounds were generated for this package.
