What's New & Changelog

Version 1.1 adds the two features players asked for most, carrying a stack and saving in the middle of a level, and fixes every issue reported since release.

Version 1.1

New: carry a stack of objects

  • While holding an object, aim at another loose object and press Interact to add it to the stack. The demo player carries up to 5 objects.
  • Placing an object brings the next one from the stack to the hand, so a full stack is emptied with quick clicks.
  • Smart selection: aiming at a target swaps a matching stacked object into the hand.
  • Configurable on the interactor: Carry Capacity, Maximum Stacked Size, Stack Offset, Stack Visual Scale, Auto Select Matching Object. New Carry In Stack flag on object definitions and a StackFilter hook for code rules.
  • New HUD prompt Add to stack and a 3/5 counter next to the object name.

Details: Carrying a stack.

New: save and continue inside a level

  • Levels autosave every 30 seconds while something changed, on pause, on quit and before scene changes. The pause menu adds a Save Progress button.
  • Opening the level again restores it silently and shows a Welcome back banner. The main menu Continue button opens the most recently saved level and level cards show In progress 37%.
  • Snapshots are deleted when the level is completed, failed or restarted.
  • New API: TidyLevelManager.SaveProgress(), DiscardSavedProgress(), ProgressSaved, ProgressRestored; TidySaveService.SaveLevelSnapshot, TryLoadLevelSnapshot, DeleteLevelSnapshot, HasLevelSnapshot, GetSavedProgress, FindMostRecentSnapshotLevel.
  • Every Tidy Object in the demo scenes now has a unique id. Run Generate Missing Scene IDs on your own scenes.

Details: Saving progress inside a level.

New: cleaning methods

  • TidyCleanable has Accepted Methods (Bare Hands, Scrubbing, Vacuum) and TidyCleaningTool has a Method. Defaults accept everything, so existing levels keep working.
  • Aiming at a surface with the wrong tool shows Needs a scrubbing tool or Needs a vacuum.
  • In the Cozy Room stains now need the sponge; empty hands and the vacuum no longer clean them.

Upgrading from 1.0

  1. Back up your project, then import the update over the existing TidyUpFramework folder.
  2. Your own player prefab keeps single-object holding (Carry Capacity 1). Raise it on the TidyInteractor to enable stacks.
  3. Mid-level saving is on by default for every Level Manager. Run Tools > Tidy Up Framework > Generate Missing Scene IDs in each level scene and save it.
  4. If you copied the demo HUD, add a Save Progress button to your pause menu and assign it to TidyPauseMenu.saveButton (optional; saving on pause works without it).
  5. Code that switches over TidyInteractionContext should handle the new CanStack value.
