Tidy Up Framework

Tidy Up + Sorting + Organizing + Placement + Satisfying Interaction Framework for Unity 6 and the Universal Render Pipeline.

New in version 1.1Carry a stack of objects, save and continue a level at any time, cleaning methods for tools and stains, tutorial shortcuts and several fixes. See What’s New.

1. Introduction

What it is

The Tidy Up Framework is a reusable toolkit for games in which the player finds, picks up, sorts, places, stacks and cleans objects until a messy space becomes organised. It is not a single game: it is the set of systems underneath one, separated from content so you can replace every model, room and rule with your own.

Why it exists

Organising games look simple but repeat the same hard problems: reliable aiming at small objects, placement that always looks neat, rules such as "red books go here" or "volumes in order", objectives, scoring, hints, input on three device families, saving and a polished UI. The framework solves those once, in a data-driven way, so a new level is mostly configuration.

What you can build

Library & museum sorting

Shelves ordered alphabetically or by volume, curated display cases.

Store & collectible shelves

Hundreds of small items sorted by type, colour and quantity.

Warehouse & workshop

Colour-coded bins, size-based pallets, tool walls.

Cosy room & unpacking

Cleaning stains, disposing clutter, placing items on surfaces.

Kitchen, garage, office

Any mix of containers, drawers, stacks and free placement areas.

Fantasy inventories

Potions, crystals and scrolls with tag-based rules.

2. Installation

  1. Requirements. Unity 6000.0 or newer with the Universal Render Pipeline (17.x), the Input System package (1.11+) and uGUI 2.0 (TextMeshPro is part of it). The Player Settings option Active Input Handling must include the Input System.
  2. Import. Import the package. All files live under Assets/TidyUpFramework.
  3. TextMeshPro resources. If Unity prompts for TMP Essential Resources, accept. They provide the default font used by the UI.
  4. Build scenes. Open File > Build Profiles and make sure the scenes in Demo/Scenes are listed, with TidyUp_MainMenu first. The demo pipeline does this automatically.
  5. Play. Open Demo/Scenes/TidyUp_MainMenu and press Play.
Using your own URP asset?The demo works with any URP asset. For the best look enable HDR, soft shadows and the Screen Space Ambient Occlusion renderer feature. Recommended settings are listed in URP Configuration.

3. Quick Start

This is the shortest path from an empty scene to a playable sorting level. The full illustrated version is in Creating Your First Level.

  1. Create a new scene and add a floor.
  2. Choose GameObject > Tidy Up Framework > Complete Level Setup. This adds the player, the level systems and the HUD.
  3. Create a category: Create > Tidy Up Framework > Category, for example Books.
  4. Create an object definition: Create > Tidy Up Framework > Object Definition and set its category to Books.
  5. Drop a few book meshes in the scene, select them and run Tools > Tidy Up Framework > Make Selected Objects Interactive. Assign the definition on the Tidy Object component.
  6. Add a shelf: GameObject > Tidy Up Framework > Placement > Shelf Row (Packed). In Acceptance > Categories add Books.
  7. Create a level: Create > Tidy Up Framework > Level Definition, add a Place Objects objective and assign the level to the Level Manager.
  8. Run Tools > Tidy Up Framework > Level Validator, fix anything it reports, then press Play.
