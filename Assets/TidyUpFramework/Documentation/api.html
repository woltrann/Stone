API Reference

The most important public types. All types live under the TidyUpFramework root namespace; the sub-namespace matches the folder.

TidyUpFramework.Core

TidyServices

Purpose: type-keyed registry for scene and application services. Methods: Register<T>(T), Unregister<T>(T), TryGet<T>(out T), Get<T>(). Events: ServiceChanged(Type).

TidyTweenRunner

Purpose: pooled, allocation-light tweening. Methods: MovePose(transform, position, rotation, duration, ease, arcHeight, completed), ScaleTo(...), Punch(transform, restScale, strength, duration, vibrato), Value(setter, duration, ease, completed, unscaledTime, delay), Kill(handle | transform | transform, kind), IsTweening(transform).

TidyTweenRunner.MovePose(book.transform, slotPosition, slotRotation, 0.3f, TidyEaseType.OutCubic, 0.1f, () => Debug.Log("Landed"));

TidyControlLock

Purpose: reference-counted locks for Movement, Look, Interaction and Cursor. Methods: Acquire(owner, channels), Release(owner), IsLocked(channel). Events: Changed.

TidyUpFramework.Objects

TidyObject (MonoBehaviour)

Important properties: Definition, InstanceId, State, CurrentTarget, IsCorrectlyPlaced, HasBeenPickedUp, MistakeCount, Category, Tags, Size, Weight, Priority, SortKey, SequenceIndex, BaseScore, capability flags, PhysicsProfile, Renderers, Colliders, LocalBounds, IsAvailableForPickup, CanCarryInStack, IsCarried.
Methods: HasTag, IsInCategory, FindTag(group), PivotPositionForSurface, CalculateWorldBounds, RestoreProgressFlags, state transitions (MarkHeld, MarkCarried, MarkMoving, MarkPlaced, MarkLoose, MarkConsumed) used by the interactor and targets.
Events: StateChanged. Dependencies: collider, optional Rigidbody.

TidyObjectDefinition, TidyCategoryDefinition, TidyTagDefinition, TidyPhysicsProfile (ScriptableObject)

Data assets described in Objects, Categories & Rules. TidyCategoryDefinition.IsOrDescendsFrom(other) walks the hierarchy.

TidyObjectRegistry (static)

All, TryGetFromCollider, FindByInstanceId; events Registered, Unregistered, AnyStateChanged.

TidyUpFramework.Rules

TidyRuleDefinition (abstract: Matches, Describe, PlayerFacingDescription) with TidyCategoryRule, TidyTagRule, TidyDefinitionRule, TidyNumericRule, TidySortKeyRangeRule, TidyCompositeRule. TidyMatchFilter (serialisable: Matches, Describe, IsEmpty, Create, ForDefinitions). TidyOrdering (Compare, IsOrdered, IsGrouped).

TidyUpFramework.Placement

TidyPlacementTarget (abstract MonoBehaviour)

Properties: TargetId, DisplayName, Acceptance, Policy, Ordering, Grouping, CompletionMode, Capacity, Occupants, IsFull, IsComplete, CorrectCount, CompletionRatio, IsOrderSatisfied, IsGroupingSatisfied.
Methods: Belongs(object), IsCompatible(object), Evaluate(query) → TidyPlacementCandidate, TryPlace(candidate, animate), TryPlaceDirect(object, animate), Release(object), AllowsRemoval(object), GetHintPoint(object).
Events: ObjectPlaced, ObjectRemoved, CompletionChanged.

var target = TidyTargetRegistry.FindById("shelf_spell_books");
var candidate = target.Evaluate(TidyPlacementQuery.WithoutAim(book));
if (candidate.IsValid)
{
    target.TryPlace(candidate);
}

Concrete types: TidySnapSlot, TidySlotGroup, TidyRowZone, TidyContainer (event FillChanged), TidyFreePlacementZone, TidyStackPoint. Registry: TidyTargetRegistry.

TidyUpFramework.Interaction

TidyInteractor

Properties: HoveredObject, HeldObject, StackedObjects, CarriedCount, CarryCapacity, IsCarryingStack, StackFilter, IsInspecting, CurrentCandidate, Context, AimCamera, ReachDistance, AimAssistMultiplier. Methods: TryAim(out hit), CenterRay(), ForcePickUp(object), ForceDrop(), DropAll(), CanStack(object), TryAddToStack(object), SelectCarried(object). Events: see Player. Dependencies: ITidyPlayerInput, optional ITidyHighlighter, optional TidyPlacementPreview.

ITidyHighlighter / TidyOutlineHighlighter, TidyPlacementPreview, TidyHoldMotion.

TidyUpFramework.Levels & Objectives

TidyLevelManager

Properties: Level, LevelId, Context, State, Trackers, Progress, TimeRemaining, Score, Combo, LastResult, SavesProgress, IsRestoring, HasPendingRestore, WasRestored. Methods: StartLevel(), AssignLevel(level), RegisterHintUsed(cost), FailLevel(), ForceComplete(), SaveProgress(), DiscardSavedProgress(). Events: LevelStarted, StateChanged, ProgressChanged, ObjectiveChanged, ObjectiveCompleted, PlacementEvaluated, AllRequiredObjectivesComplete, LevelCompleted, LevelFailed, ProgressSaved, ProgressRestored.

levelManager.LevelCompleted += result =>
{
    Debug.Log(result.Stars + " stars, " + result.Score + " points in " + result.TimeSeconds + " s");
};

TidyLevelDefinition (CalculateStars), TidyLevelCatalog (FindById, FindByScene, NextAfter), TidyLevelResult, TidyLevelContext, ITidyProgressService, TidySceneLoader.

TidyObjectiveDefinition (abstract Evaluate) and concrete objectives; TidyObjectiveTracker (Progress, IsComplete, IsFailed, Title; events Changed, CompletedFirstTime); TidyObjectiveProgress (Current, Target, Ratio, IsComplete).
