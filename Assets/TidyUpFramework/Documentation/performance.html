Performance, Mobile & URP

Organising games put hundreds of small objects on screen. The framework is built so that the number of objects costs little when nothing is happening.

Performance optimisation

What the framework already does

AreaApproach
Per-object costTidyObject has no Update. Objects at rest are kinematic and do nothing until touched.
AimingOne sphere cast per frame with a pre-allocated hit buffer; collider-to-object look-ups are cached in dictionaries.
AnimationA single pooled tween runner animates every object and disables itself when idle.
ObjectivesRe-evaluated only when something changes (dirty flag, batched once per frame) plus a slow 2 Hz refresh for time-based goals.
Highlights and ghostsGraphics.RenderMesh draws extra passes without changing materials, so SRP batching and instancing stay intact.
FeedbackParticles are pooled; audio sources are pooled; cues have cooldowns.
UIViews update on events, not every frame (timer text updates once per second).
GarbageGameplay loops avoid allocations; string building is limited to UI changes.

What you should do in your scenes

  • Mark environment geometry Static (batching, occlusion, reflection probes). Demo builders do this for every room.
  • Enable GPU Instancing on materials shared by many props (all demo materials have it on) and keep the SRP Batcher enabled.
  • Use controlled physics profiles for small, numerous props; reserve physics profiles for a few large ones.
  • Prefer BoxColliders on props. Convex mesh colliders are fine for odd shapes; avoid non-convex colliders on movable objects.
  • Keep shadow-casting on large props only: the demo disables shadows on tiny objects automatically.
  • Use Light Layers or limited ranges for candle-style point lights.

Mobile optimisation

  • Use the Mobile URP asset (forward renderer, no SSAO, lower shadow resolution, render scale 0.8) and the Mobile quality level.
  • Set Shadows to Low or Off and Render Scale to 70–85% in the in-game settings for older devices.
  • Enable Fill In Order on slot groups and generous trigger colliders on targets so placement is easy with taps.
  • Increase the interactor's Aim Radius or let players raise Interaction Assist.
  • Limit simultaneously visible interactive objects to a few hundred and favour texture atlases.
  • Use TidyPlayerPrefsStorage on WebGL.
