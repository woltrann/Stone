Creating Your First Level

A complete walkthrough: a small study where the player shelves books by colour, files an encyclopaedia in order and clears the floor onto a desk. No code is written.

Before you startOpen Demo/Scenes/TidyUp_Sandbox to see the finished result of this tutorial, or follow along in a new scene. The demo assets used here live in Demo/Prefabs/Library and Demo/Data; use your own models if you prefer.

Tutorial: creating a book sorting level

  1. Create the scene and a Level Definition.

    Create a scene, add a floor and save it as MyStudy. In the Project window choose Create > Tidy Up Framework > Level Definition, name it Level_MyStudy, set Display Name to "My Study" and Scene Name to MyStudy.

  2. Create categories.

    Create > Tidy Up Framework > Category: Books, then History, Star Charts and Encyclopaedia with Books as their parent. Give each a display colour.

  3. Create book object definitions.

    Create > Tidy Up Framework > Object Definition for each book. Set the category and add a colour tag (Red for history, Blue for star charts). For encyclopaedia volumes set the category to Encyclopaedia and a Sequence Index (1, 2, 3...). Tick Stackable if books may also be stacked.

  4. Place the books.

    Drag your book models (or the demo prefabs) into the scene and scatter them on the floor and desk. Select them and run Tools > Tidy Up Framework > Make Selected Objects Interactive, then assign each definition. Demo prefabs are already configured.

  5. Place shelves.

    Add a bookcase model. On each shelf board choose GameObject > Tidy Up Framework > Placement > Shelf Row (Packed). Position the row at the left end of the board, set Length to the board width and Item Euler Rotation to (0, 90, 0) so spines face the player. Resize the aim trigger to cover the shelf opening.

  6. Configure shelf rules.

    Top row: Acceptance > Categories = Books, Required Tags = Red, Target Id = shelf_red. Middle row: the same with Blue (shelf_blue). Bottom row: Categories = Encyclopaedia, Ordering = Sequence, Completion Mode = When All Matching Objects Placed (shelf_history). Add a Free Placement Zone on the desk that accepts Curiosities.

  7. Create objectives.

    Create > Tidy Up Framework > Objectives > Place Objects: filter Categories = Books, Required Tags = Red, Required Count = 0 (all), title "Shelve the red books {current}/{target}". Repeat for blue. Add Complete Targets with target id shelf_history, title "File the encyclopaedia in order". Optionally add a Place Objects objective for the desk and tick Optional. List them in Level_MyStudy.

  8. Add the level systems.

    GameObject > Tidy Up Framework > Complete Level Setup. Assign Level_MyStudy to the Level Manager. Move the player to the doorway.

  9. Validate and test the level.

    Run Tools > Tidy Up Framework > Level Validator. Fix errors (missing aim colliders, duplicate ids, scene not in build) with the Fix buttons, then press Play: pick books up, aim at the shelves, watch the ghost preview, complete the objectives and read your results.

  10. Add it to the game and build.

    Add Level_MyStudy to your Level Catalog, set its unlock requirement, add the scene to the build list and build. It appears in Level Select with stars and best times.
